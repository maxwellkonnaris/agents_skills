agents_skills tutorial

Layer your agent instructions

1. Prompt

The prompt is for the immediate task: the goal, context, constraints, and done-when criteria.

2. AGENTS.md

AGENTS.md is for stable behavior that should apply almost every time: safety, style, Git rules, scientific reasoning, and verification habits.

3. Skills

Skills are focused workflows. Use them for repeated tasks like Slurm debugging, R package review, statistical learning, or scientific writing.

4. Scripts

Scripts are deterministic helpers. Use them when a command should be reliable, reusable, and easy to inspect.

5. Rule of thumb

If it is broad behavior, put it in AGENTS.md. If it is a repeated workflow, make it a skill. If it is executable, make it a script.
